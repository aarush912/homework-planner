# Study Hall — Homework Planner

A simple, responsive homework planner that keeps assignments, classes, due dates, and weekly progress together. It runs in your browser and saves your planner on this device with local storage.

## Use it

Open `index.html` in a browser, add your classes, then add assignments. Use the sidebar to filter by class or switch between today, upcoming, and all assignments. Check the box beside an assignment when it is complete.

No install or build step is required.

## Your data

Planner data stays in the browser on the device where you enter it. Clearing site data will remove it. This app does not currently sync between devices.
